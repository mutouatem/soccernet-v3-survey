读前说明

两篇挑战赛报告里，每个方法只有一段文字摘要，报告本身没有任何公式，也没有超参数。RFES-ReID 是正式论文，有编号公式 Eq. 1–7。所以本页的公式有三种来源，用色标区分：

  • 原文论文里有编号的公式，我回原文逐条对过。只出现在 RFES-ReID 一节。
  • 标准定义报告只说"用了 ArcFace / InfoNCE / DINO…"，这里给的是该组件在其原始论文中的通行写法。参赛队的具体取值与改动，报告没写。
  • 我的形式化原文只有文字或示意图，公式是我按描述写出来的；属于推断，引用前请自行核对。

范围：re-ID 任务的全部方法，加上与身份直接相关的跟踪冠军 TrackMerger。动作定位、标定、字幕等任务不在本页。文中 #编号 与综述的论文索引一致。

一、RFES-ReID（#103）

Akan, Varlı, Bhuiyan. An enhanced Swin Transformer for soccer player reidentification. Scientific Reports 14:1139 (2024)。语料里唯一在 SoccerNet-v3 跨视角 re-ID 数据上做方法研究的论文。

整体流程

  • 训练：图像 → RFES 骨干 → 特征 → 三个损失相加。
  • 推理：图像 → 骨干 → 特征 → 初始排序 → k-reciprocal 重排序。
  • 骨干是 Swin-T，四个 stage 的 block 数为 2 / 2 / 6 / 2，输入 224×224，窗口按 4×4 网格划分。

Swin Transformer 回顾

把 \(H\times W\times C\) 的特征切成互不重叠的 \(M\times M\) 窗口，每个窗口内各自做自注意力。对一个窗口的特征 \(X\in\mathbb{R}^{M^2\times C}\)：

原文 Eq. 1窗口内的 Q / K / V
\[ Q = XP_Q,\qquad K = XP_K,\qquad V = XP_V \]
\(P_Q, P_K, P_V\) 在所有窗口之间共享；\(Q,K,V\in\mathbb{R}^{M^2\times d}\)。
原文 Eq. 2带相对位置偏置的窗口注意力
\[ \mathrm{Attention}(Q,K,V)=\mathrm{SoftMax}\!\left(\frac{QK^{\top}}{\sqrt{d}}+B\right)V \]
\(B\) 是可学习的相对位置编码。

窗口划分如果每层都一样，窗口之间就没有信息交换。Swin 的做法是相邻两个 block 交替使用规则窗口（W-MSA）与平移了 \((M/2, M/2)\) 的窗口（SW-MSA）：

原文 Eq. 3连续两个 Swin block
\[ \begin{aligned} \hat X^{l} &= \text{W-MSA}\big(\mathrm{LN}(X^{l-1})\big) + X^{l-1}\\ X^{l} &= \mathrm{MLP}\big(\mathrm{LN}(\hat X^{l})\big) + \hat X^{l}\\ \hat X^{l+1} &= \text{SW-MSA}\big(\mathrm{LN}(X^{l})\big) + X^{l}\\ X^{l+1} &= \mathrm{MLP}\big(\mathrm{LN}(\hat X^{l+1})\big) + \hat X^{l+1} \end{aligned} \]
LN 为 LayerNorm；MLP 是两层全连接，中间夹 GELU。

Regional Feature Extraction Block（论文的核心改动）

动机：位置编码加窗口注意力，对局部相关性和空间结构的编码不够；球员缩略图又小又糊，纯 attention 抓不住细节。做法是在每个 stage 的 Swin block 之前插入一个空洞卷积残差分支，给 Transformer 补上 CNN 式的局部感受野。原文只有文字和 Fig. 6，按它的描述写出来是：

我的形式化RFEB：token → 特征图 → 空洞卷积残差 → token
\[ \begin{aligned} F &= \mathrm{reshape}(X) && (B,\,HW,\,C)\rightarrow(B,\,C,\,H,\,W)\\ F' &= F + \mathrm{GELU}\big(\mathrm{DConv}_{3\times3}^{\,r=2}(F)\big)\\ X' &= \mathrm{reshape}(F') && (B,\,C,\,H,\,W)\rightarrow(B,\,HW,\,C) \end{aligned} \]
\(r\) 是空洞率（dilation）。\(X'\) 送入后面的 Swin block。
原文的一处错误。论文说 3×3、dilation=2 的卷积"有 7×7 的感受野"。按等效核公式算，实际是 5×5。7×7 是"先 1-dilated、再 2-dilated 两层堆叠"的结果，出自空洞卷积的原始论文，疑似误引。不影响实验，但引用时别照抄。
标准定义空洞卷积的等效核大小
\[ k_{\text{eff}} = k + (k-1)(r-1) = 3 + 2\times 1 = 5 \]

融合损失

原文 Eq. 4交叉熵：保证分类正确
\[ L_{CE}(p_i, y_i) = -\,y_i \log p_i \]
\(p_i\) 是第 \(i\) 个样本的预测概率，\(y_i\) 是真实标签。
原文 Eq. 5Triplet：同一个人拉近，不同的人推远
\[ L_T = \max\big(d_{a,p} - d_{a,n} + \mathrm{margin},\; 0\big) \]
\(d\) 为欧氏距离，margin = 0.3。原文没说怎样挖掘三元组；batch 是 8 个身份 × 每个 4 张，通常意味着 batch-hard 挖掘（我的推断）。
原文 Eq. 6Focal：把梯度让给难样本
\[ L_F = \sum_{i=1}^{n} (1-p_i)^{\gamma}\, L_{CE}(p_i, y_i) \]
\(\gamma=2\)，在 SoccerNet-v3 上扫参选出（Fig. 9），但论文没说用的是哪个 split。已经分得很对的样本（\(p\to1\)）几乎不贡献损失。v3 里每个身份只有几张图、同队球员互为难负样本，这一项就是为此加的。
原文 Eq. 7三项等权相加
\[ L_{Fusion} = L_{CE} + L_T + L_F \]

k-reciprocal 重排序

原文只有文字描述，并说参数沿用原论文（Zhong et al., CVPR 2017）。直观含义：如果 A 的近邻里有 B、B 的近邻里也有 A，而且两人的"近邻圈"高度重合，那它们更可能是同一个人。

标准定义第一步：互为 k 近邻的集合
\[ \mathcal{R}(p,k) = \big\{\, g \;:\; g\in N(p,k)\ \wedge\ p\in N(g,k) \,\big\} \]
\(N(p,k)\) 是 \(p\) 的前 \(k\) 个近邻。
标准定义第二步：扩展集合
\[ \mathcal{R}^{*}(p,k) \leftarrow \mathcal{R}(p,k)\,\cup\,\mathcal{R}\big(q,\tfrac{k}{2}\big)\quad \text{if}\quad \Big|\mathcal{R}(p,k)\cap\mathcal{R}\big(q,\tfrac{k}{2}\big)\Big| \ \ge\ \tfrac{2}{3}\,\Big|\mathcal{R}\big(q,\tfrac{k}{2}\big)\Big|,\qquad \forall q\in\mathcal{R}(p,k) \]
标准定义第三步：编码成向量，并用近邻做局部扩展
\[ V_{p,g} = \begin{cases} e^{-d(p,g)} & g\in\mathcal{R}^{*}(p,k)\\[2pt] 0 & \text{otherwise} \end{cases} \qquad\qquad V_p \leftarrow \frac{1}{|N(p,k_2)|}\sum_{g\in N(p,k_2)} V_g \]
标准定义第四步：Jaccard 距离与原始距离加权
\[ d_J(p,g) = 1 - \frac{\sum_{j}\min\big(V_{p,j},\,V_{g,j}\big)}{\sum_{j}\max\big(V_{p,j},\,V_{g,j}\big)} \qquad\qquad d^{*}(p,g) = (1-\lambda)\,d_J(p,g) + \lambda\, d(p,g) \]
原论文默认 \(k_1=20,\ k_2=6,\ \lambda=0.3\)。RFES-ReID 原文把第二项写成"Manhalanobis distance"，应是马氏距离的拼写错误。
复现时要自己验证的一点。按我的粗略估算，每个 action 的 gallery 只有 20 张左右，\(k_1=20\) 几乎覆盖整个 action，真正起作用的是"互为近邻"这个条件。论文没说重排序是按 action 做还是全局做。

设置与结果

  • 数据：只用 train split（248,234 个样本）训练，在 test split 上评测：query 11,777 张、gallery 34,989 张；身份只在 action 内有效，query 只与同一 action 的 gallery 比较。
  • 预处理：删掉训练集中少于 4 张图的身份；随机水平翻转、随机裁剪、random erasing。
  • 优化：AdamW，lr 1e-3，weight decay 0.05，cosine 衰减 + 10 epoch 线性 warm-up，共 120 epoch；单张 RTX 4080。

R1 Inspur 冠军 · mAP 91.68

报告里说了什么主要难点是样本不均衡，以及多输入分辨率带来的不鲁棒。删掉少于 3 张图的身份，用 focal loss；骨干选 ResNeSt269，分类头为 Arc-Softmax 与 Cos-Softmax 的组合；AutoAug、ColorJitter、RandomErase，概率均为 0.5；单模型调好后叠加常用技巧：多输入分辨率模型融合、加入测试阶段数据、无监督域自适应。
标准定义Focal loss（Lin et al.）
\[ L_{focal} = -\,(1-p_t)^{\gamma}\,\log p_t \]
\(p_t\) 是真实类别的预测概率。
标准定义ArcFace（Arc-Softmax）：在角度上加 margin
\[ L_{arc} = -\log\frac{e^{\,s\cos(\theta_{y}+m)}}{e^{\,s\cos(\theta_{y}+m)}+\sum_{j\ne y} e^{\,s\cos\theta_j}} \]
标准定义CosFace（Cos-Softmax）：在余弦值上减 margin
\[ L_{cos} = -\log\frac{e^{\,s(\cos\theta_{y}-m)}}{e^{\,s(\cos\theta_{y}-m)}+\sum_{j\ne y} e^{\,s\cos\theta_j}} \]
\(\theta_j\) 是 L2 归一化特征与第 \(j\) 类权重向量的夹角，\(s\) 为缩放，\(m\) 为 margin。两者都让同一个人的特征在超球面上聚得更紧。
  • ResNeSt：把通道分组，组内做 split-attention（用全局池化得到的权重对各个 split 加权求和）；269 是层数规格。
  • 多分辨率融合：报告没给做法。常见做法是训练几个输入尺寸不同的模型，再拼接特征或平均距离矩阵。针对的正是"分辨率差异大"。
  • 无监督域自适应：报告没说用哪种方法。re-ID 里的典型流程是：用已训好的模型给目标集提特征 → 聚类（如 DBSCAN）得伪标签 → 用伪标签微调 → 重复。
这一条决定了成绩能不能拿来对比。"加入测试阶段数据 + 域自适应"意味着冠军成绩用到了 challenge 集的无标签图像。方法论文里一般不接受这样做。

R2 MGSoccer-ViT 腾讯 · 91.48（test 91.28）

报告里说了什么CNN 与 ViT 两路分别表示球员图像。CNN 按 Multiple Granularity Network 设计，用独立分支表示全局与不同粒度的局部特征；ViT 参照 TransReID，把图像切成等大的 patch 作为 token 序列。所有骨干用 LUPerson 上的自监督预训练初始化。ArcFace + hard triplet。针对 SoccerNet 的分布，删掉所有长尾身份，并用 action-based sampler 在不同 action 中采等量身份。增强：翻转、擦除、padding 后裁剪、AutoAugment、AugMix。
标准定义MGN：三个分支的特征拼接
\[ f = \big[\, f^{G}_{g},\; f^{P2}_{g},\; f^{P3}_{g},\; f^{P2}_{1}, f^{P2}_{2},\; f^{P3}_{1}, f^{P3}_{2}, f^{P3}_{3} \,\big] \]
ResNet 后半段分三支：全局分支 G；把特征图横切成 2 条的 P2；横切成 3 条的 P3。每支有一个全局向量 \(f_g\)，局部分支另有各条的向量。原论文里全局向量用 triplet，各局部向量用分类损失。
标准定义TransReID / ViT 的输入序列
\[ Z_0 = \big[\, x_{cls};\ \mathcal{E}(x_1);\ \mathcal{E}(x_2);\ \dots;\ \mathcal{E}(x_N) \,\big] + \mathcal{P} \]
\(\mathcal{E}\) 是 patch 的线性映射，\(\mathcal{P}\) 是位置编码。TransReID 原论文还有 JPM 与 SIE 两个模块，报告没说是否使用。
标准定义Batch-hard triplet
\[ L_{BH} = \sum_{a}\Big[\, m + \max_{p:\,y_p=y_a} d(a,p)\ -\ \min_{n:\,y_n\ne y_a} d(a,n) \,\Big]_{+} \]
每个 anchor 取 batch 内最远的正样本和最近的负样本。

LUPerson 是约 400 万张无标签行人图的数据集。它是唯一同时报告 test 与 challenge 成绩的队，从它看两个 split 难度接近。

R3 MTVACV 美团 · 90.11

报告里说了什么难点是球员外观高度相似，以及球员之间严重的相互遮挡。① 面向目标域的自监督预训练：筛选 LUPerson，保留对 SoccerNet ReID 的 Catastrophic Forgetting Score 高的图像作为预训练集，用 DINO 训练 ViT-B。② 设计"可见性与重要性感知"的特征学习框架，提取不同身体部位的判别特征。③ 模型融合：直接平均不同模型的距离矩阵。
标准定义DINO：学生匹配教师，教师是学生的滑动平均
\[ \begin{aligned} P_s(x) &= \mathrm{softmax}\big(g_{\theta_s}(x)/\tau_s\big), \qquad P_t(x) = \mathrm{softmax}\big((g_{\theta_t}(x)-c)/\tau_t\big)\\[4pt] L &= -\sum_{x\in\{x^{g}_{1},x^{g}_{2}\}}\ \sum_{x'\in V,\ x'\ne x} P_t(x)^{\top}\log P_s(x')\\[4pt] \theta_t &\leftarrow \lambda\,\theta_t + (1-\lambda)\,\theta_s, \qquad c \leftarrow m\,c + (1-m)\,\tfrac{1}{B}\textstyle\sum_{i} g_{\theta_t}(x_i) \end{aligned} \]
\(V\) 是同一张图的多个裁剪视图，\(x^g\) 是其中的全局视图；减中心 \(c\) 与更低的 \(\tau_t\)（锐化）共同防止坍塌。不需要标签。
我的形式化可见性感知的部件距离（同类方法 BPBReID / PRTreID 的形式）
\[ d(q,g) = \frac{\sum_{k} v^{q}_{k}\, v^{g}_{k}\ \big\lVert f^{q}_{k}-f^{g}_{k}\big\rVert}{\sum_{k} v^{q}_{k}\, v^{g}_{k}} \]
\(v_k\) 是第 \(k\) 个部位的可见性，只对双方都可见的部位求平均。报告只有一句话、没有公式；"重要性"应是再给每个部位一个可学习权重。
标准定义距离矩阵平均
\[ D = \frac{1}{M}\sum_{m=1}^{M} D_m \]

CFS 出自 TransReID-SSL 论文，用来衡量预训练数据与下游数据的域差距。它的精确公式我没有把握，这里不写，要用时请查原论文。

R4 gunners / Sports Re-ID Comandur · 89.47

报告里说了什么不用随机采样，而用一种新的流程为每个 batch 选样本；用带 centroid 的损失更好地分开 embedding；最后做 model soup 进一步提高 mAP。模型只用 ImageNet 预训练。
我的形式化Centroid triplet 的通用形式
\[ c_{P} = \frac{1}{|P|}\sum_{i\in P} f(x_i), \qquad L = \Big[\, \lVert f(a)-c_{P}\rVert - \lVert f(a)-c_{N}\rVert + m \,\Big]_{+} \]
\(c_P\)、\(c_N\) 是正、负身份的特征均值。他实际用的形式要看独立论文（arXiv 2206 开头，不在语料里）。
标准定义Model soup：对权重取平均，不是对预测取平均
\[ \theta_{soup} = \frac{1}{M}\sum_{m=1}^{M}\theta_m \]
推理时只跑一个模型，没有集成的开销。

它是前几名里最省的配方：不用 LUPerson，不用集成。"分层采样"大概是按"比赛 → action → 身份"逐层抽样（我的推断）。

R5 MIG 89.44

报告里说了什么改进经典采样策略：随机取 A 个 action、I 个身份、每身份 K 张图，得到 A×I×K 的 batch；action 总数很大加上随机性，可以避免同一球员的不同身份出现在同一 batch。batch 内用非参数 InfoNCE。骨干是 TransReID-SSL 里带 ICS 的 ViT。基于 Transformer 的自注意力提出一种特征融合方法，为原始 query 特征生成精炼特征。5 个模型（输入尺寸与预训练不同）集成生成最终距离矩阵。
这是整份报告里对你最有用的一句话。v3 的身份只在 action 内有效，同一个人在另一个 action 里是另一个 ID。如果同场比赛的几个 action 进了同一 batch，这个人会被当成自己的负样本。任何在 v3 上训练的对比/度量学习都要处理这个假负样本问题。
标准定义batch 内的非参数 InfoNCE（多正样本形式）
\[ L_i = -\log\frac{\sum_{p\in P(i)} \exp\big(z_i^{\top} z_p/\tau\big)}{\sum_{k\ne i} \exp\big(z_i^{\top} z_k/\tau\big)} \]
\(z\) 为 L2 归一化特征，\(P(i)\) 是 batch 内与 \(i\) 同身份的样本。"非参数"指没有分类层权重。v3 身份数极多、每身份只有几张，分类头很难学，这一点对它特别合适。
我的形式化基于注意力的 query 精炼（报告没给公式）
\[ q' = q + \sum_{j}\mathrm{softmax}_j\!\Big(\frac{q^{\top} g_j}{\sqrt d}\Big)\, g_j \]
让 query 从候选特征里聚合信息，作用类似重排序里的 query expansion。

ICS：用带 IBN 的卷积 stem 替换 ViT 的线性 patch embedding，训练更稳定。

R7 ReBatch 88.36

报告里说了什么RE(s)IDnet 是以 ResNet 变体为骨干的模型集成。单个模型用欧氏 triplet 损失与 ID/分类损失的加权和，后者占比很小。同一 action 的图像放在同一 batch，以保证用到最好、最难的三元组。循环学习率，从 warm-up 周期开始。预处理用 coarse dropout 等增强。后处理改变 gallery 排名：如果所有模型都认为某张图是某个 query 的第一名，就在其它所有 query 的排名里把这张图后移。
我的形式化损失
\[ L = L_{triplet} + \lambda\, L_{ID}, \qquad \lambda \ll 1 \]
我的形式化排名互斥后处理
\[ \text{if}\ \ \forall m:\ \arg\min_{g} D_m(q,g) = g^{*}\quad\Longrightarrow\quad \forall q'\ne q:\ \text{demote } g^{*} \text{ in the ranking of } q' \]
利用的事实是：同一 action 里，一张 gallery 图只属于一个人。可以看成贪心版的分配问题；升级版是在 action 内做二分图匹配，代价里再加球场坐标距离。

跟踪冠军 TrackMerger Kalisteo · HOTA 93.64 / AssA 88.06

这一届提供全部真值检测框，只评关联（baseline HOTA 70.89）。

  1. 逐帧生成短轨迹：检测与已有轨迹用匈牙利算法匹配，准则是框的 IoU 与中心距。报告没写两个准则怎样组合。
  2. 自监督微调 re-ID 网络：正样本取自与 anchor 同一条轨迹，负样本取自与 anchor 同时存在的其它轨迹——同一帧里的两个框必然不是同一个人。
  3. 合并轨迹：按 re-ID 向量距离合并，并禁止同帧重复身份、禁止相邻帧"瞬移"。
我的形式化轨迹自监督 triplet 的取样规则
\[ L = \big[\, d(a,p) - d(a,n) + m \,\big]_{+},\qquad p\in \mathcal{T}(a),\qquad n\in \mathcal{T}'\ \ \text{with}\ \ \mathcal{T}'\ne\mathcal{T}(a),\ \ \mathrm{frames}(\mathcal{T}')\cap\mathrm{frames}(\mathcal{T}(a))\ne\varnothing \]
\(\mathcal{T}(a)\) 是 anchor 所在的轨迹。不需要任何人工标注。

组织者总结的七条共性经验

  1. 预处理：删掉训练集中样本太少的身份。
  2. 利用 action id、game id 等额外标签，手工设计 batch 采样策略。
  3. 常规增强：水平翻转、Random Erasing、随机裁剪、AutoAugment、AugMix、Color Jitter。
  4. 用强基线：TransReID-SSL（ViT 骨干 + LUPerson 无监督预训练）。
  5. 特定的度量学习损失：Focal、自定义 Centroid、InfoNCE、ArcFace。
  6. 在 challenge 集上做推理期的无监督域自适应微调。
  7. 推理时融合多个模型的预测来计算最终距离。

R1 CLIP-ReIdent Habel, Deuser, Oswald · 93.26（test 93.51）

报告里说了什么方法主要基于他们的论文 CLIP-ReIdent: Contrastive Training for Player Re-Identification，它也是 2022 年 MMSports（DeepSportradar 篮球）球员 re-ID 挑战的冠军。用 OpenCLIP 与 OpenAI 的三个 CLIP 模型做集成；训练时用自定义采样策略把同一 action 的球员一起采样；后处理用自己设计的按 action 重排序；CLIP 的视觉编码器用对比训练微调，目标是 InfoNCE，数据为 train + valid。
标准定义CLIP 原本的图文对比目标
\[ L_{CLIP} = \tfrac12\big(L_{i\to t}+L_{t\to i}\big), \qquad L_{i\to t} = -\frac{1}{N}\sum_{i=1}^{N}\log\frac{\exp\big(v_i^{\top}t_i/\tau\big)}{\sum_{j=1}^{N}\exp\big(v_i^{\top}t_j/\tau\big)} \]
\(v\)、\(t\) 分别是归一化的图像与文本特征。
我的形式化CLIP-ReIdent 的微调目标：把文本换成同一球员的另一张图
\[ L = -\frac{1}{N}\sum_{i=1}^{N}\log\frac{\exp\big(z_i^{\top}z_i^{+}/\tau\big)}{\sum_{k=1}^{N}\exp\big(z_i^{\top}z_k^{+}/\tau\big)} \]
\(z_i\) 与 \(z_i^{+}\) 是同一球员两张图的视觉特征。按我对其独立论文的印象，损失是对称的、温度可学习；该论文不在语料里，需自行核实。
  • 采样器：同一 action 的球员放在一起。batch 内的负样本就是同一时刻场上的其他人（包括同队球员），是天然的难负样本；同时避开了 MIG 所说的跨 action 假负样本。
  • 按 action 重排序：报告没给细节。它利用的是 action 内候选集很小、结构固定这一点，与 ReBatch 的互斥调整属于同一类。
  • 为什么 CLIP 管用：同组作者在 DeepSportradar-v2（#57）里给过解释——CLIP 零样本就能捕捉球衣号、颜色这些属性，而这些属性不太受视角影响。

跟踪冠军 TrackMerger v2 Kalisteo · HOTA 75.61

这一届不再提供真值检测框，要做完整的检测加关联（baseline 42.38），所以与 2022 的 93.64 不可比。相对第一版的变化：

  • 检测换成 YOLO-X。
  • 逐帧关联做两次匈牙利匹配（IoU 与中心距），Kalman 滤波带相机运动补偿。
  • 在球员交叉处把 tracklet 切开，得到"无歧义 tracklet"。
  • 用这些 tracklet 以 triplet 微调 Multiple Granularity Network，正负样本取法与第一版相同。
  • 按 re-ID 向量距离迭代合并，避免身份重复与"瞬移"。

整体结论：上面所有方法对视角都没有任何显式建模，全靠度量学习或对比学习让模型自己消化远景与近景的差异；而且全部是单帧方法。challenge 的 91–93 靠的是集成、大规模预训练和推理期自适应，单模型、不看测试数据时是 85–87。你的空间就在"显式处理视角"和"序列级匹配"这两点上。
